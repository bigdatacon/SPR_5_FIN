Проект анализа видео для игры манкрафт на 2 моделях FCOS и YOLO8 - обученных на 12 эпохах на стандартных аугуменациях.
Данные имеют сильный дисбаланс и модель желательно дообучать на редких классах и мелких объектах, попробую это сделать в следующей редакции если успею.

На текущий момент основные вывод в файле pdf отчета : 
- artifacts/metrics/report.pdf

Демонстрация работы обработки видео в : 
-artifacts/video и в файле noutbook.ipnyb


для FCOS
 - основной код в ноутбуке
 - конфиги в configs/focs/fcos_minecraft.py

 Для YOLO:
 - обучение модели в train_yolo_minecraft.py
 - оценка модели в evaluate_yolo.py
 - формирование labels для картинок - в ноутбуке (зкоментировано так как сделал локально и уже скопировал папку datasets со всем содержими на ВРМ)
- data.yaml  - в папкe datasets
